# context-keeper

A Claude Code plugin that keeps long coding sessions clean by maintaining a structured, repo-local working memory: current task, decisions, failed attempts, changed files, and next steps.

## Install (global)

```bash
git clone https://github.com/jbhati305/context-keeper.git
cp -r context-keeper/skills/. ~/.claude/skills/
```

That's it. Skills are available in any new Claude Code session.

## Quickstart

```
Use context-keeper:init          ← run once per repo
Use context-keeper:recall        ← start of every session
Use context-keeper:update        ← after finishing a chunk of work
Use context-keeper:compact       ← when context files get long
Use context-keeper:handoff       ← before closing or handing off
```

## The five skills

| Skill | What it does |
|-------|-------------|
| `context-keeper:init` | Scans your repo, creates `.claude/context/` with structured memory files |
| `context-keeper:recall` | Reads all context files, surfaces failed attempts, then continues your task |
| `context-keeper:update` | Upserts changed files, decisions, failures, and next steps into memory |
| `context-keeper:compact` | Prunes stale entries — failed attempts are compressed, never deleted |
| `context-keeper:handoff` | Generates a clean `HANDOFF.md` safe to paste into PRs or Slack |

## Context files (per repo)

Created in `.claude/context/` when you run init:

```
.claude/context/
  CURRENT_TASK.md      ← goal, scope, project overview, status
  DECISIONS.md         ← architectural and implementation decisions
  FAILED_ATTEMPTS.md   ← what was tried, why it failed, retry conditions
  CHANGED_FILES.md     ← files touched and why
  NEXT_STEPS.md        ← immediate / upcoming / blocked work
  HANDOFF.md           ← generated by handoff mode
```

**Git strategy:** Your call. The skill warns about secrets. Many teams commit `.claude/context/` so context survives machine switches and is shareable with teammates.

## ⚠️ Security

Never store API keys, tokens, passwords, or connection strings in context files. The skill will warn you if it detects patterns that look like secrets.
